# Repository instructions

This repository is maintained by Prashant Singhal as a public collection of reusable AI skills.

- Do not create new skills or write content into skill files without the owner's explicit approval for that work.
- Keep planned skill files empty until their content is approved for development.
- The planned topics in the README do not authorize drafting their instructions.
- Do not publish to npm unless the owner explicitly requests it.

- Follow the Agent Skills specification: each published skill is a self-contained folder with a `SKILL.md` containing `name`, `description`, and concise agent instructions. Use optional `references/`, `scripts/`, and `assets/` only when needed. Keep empty placeholders in `planned/`. Do not add custom command routers or vendor-specific configuration unless explicitly requested.
- Keep coordinator references aligned with their corresponding standalone skills when updating a concern.
